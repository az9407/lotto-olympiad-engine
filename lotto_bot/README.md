# 로또 주간 자동 학습 봇

로또 새 회차가 올라오면 Actions 워크플로 `로또 주간 자동 학습`이 돌아서 텔레그램 @lotto_pension_bot 으로 보냅니다.
연금복권 쪽 pension720 폴더와 워크플로는 따로 돌고, 봇 토큰 시크릿 TELEGRAM_BOT_TOKEN 과 대화방 기록만 같이 씁니다.

파일
- run_lotto.py: 새 회차 확인, 분석, 자동 학습, 전송
- lotto_engine.py: 최근 250회 국면 패턴 엔진, 8,145,060개 전체 채점
- tuner.py: 자동 학습
- state/lotto.json: 보낸 후보, 학습 기록
- results/lotto_NNNN.txt: 회차별 보낸 메시지

보내는 내용
- 당첨번호와 1등 정보, 지난번 보낸 후보 10개 결과
- 왜 이 번호였나: 합계·홀짝·이월수, 맞은 규칙과 빗나간 규칙, 엔진 순위
- 스스로 학습: 설정별 성적, 뺀 설정, 새로 만든 설정, 다음 회차에 쓸 설정
- 다음 회차 패턴 상위 10개, 겹침 3개 이하, 번호별 4회 이하

자동 학습
- 설정 6개를 따로 굴림: 시간 가중치, 적중률 문턱, 규칙 수, 수축 강도, 인기회피 비중, 구성필터
- 새 회차마다 설정별로 그 회차 이전 데이터만으로 엔진을 돌려 실제 번호가 상위 몇 %였는지 채점
- 최근 12회 가중 평균으로 꼴찌를 빼고, 1등 설정을 조금 바꾼 새 설정을 최근 6회로 채점해 투입
- 다음 회차는 성적 1등 설정으로 뽑음
- 첫 실행 약 12분, 이후 매주 약 4분

확인 시각: 토 21:20·22:20·23:20, 일 09:20·21:20 KST
데이터: 공개 저장소 nostra-team/nostra-data 의 history.json
다시 보내기: Actions → 로또 주간 자동 학습 → Run workflow, force 칸에 yes
로컬 시험: python lotto_bot/run_lotto.py --dry-run
